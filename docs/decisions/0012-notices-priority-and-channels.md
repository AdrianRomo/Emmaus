# 0012 - Avisos: three levels of priority, and the channels beyond Emmaus

- **Status:** accepted (owner, 2026-11-17, answering issue #70)
- **Date:** 2026-11-17

## Decision

| Channel | Decision |
|---|---|
| Inside Emmaus | Built; it stays the source of truth |
| "Compartir por WhatsApp" link | Now |
| E-mail, with each person's preferences | Next |
| WhatsApp Business API | Later, only if demand justifies it |

1. Sharing by WhatsApp sends a short, generic message with a link to the notice. The message never
   carries the notice's title or text (a group's notice is restricted and a message is forwarded
   freely) and the link never bypasses sign-in or authorization.
2. Urgency is a level of a notice, not another kind of content: **normal, importante, urgente**.
3. An urgent notice may show prominently and ask for "Enterado". That acknowledgement is not proof
   that an emergency message was delivered, and the product says so to who publishes.
4. Who may publish an urgent notice is a church policy. Default: only the church administration; who
   guides a group may publish up to "importante" for their group. It should become a setting of the
   church, not a rule written for the first church.
