Like the public page of an event it extends the skeleton and not base.html, so there is no rail, no bar and no form, whoever reads it: a signed-in person gets the same bytes. It shows ONLY what the administration published on purpose: the church's name and logo, the welcome, when it meets, where, how to ask, the events that have a public page and the resources marked one by one.
